# 小球大师 🏓

乒乓球比赛视频自动剪高光。打乒乓球录了视频，回放时却要一路拖进度条找精彩球？**小球大师**帮你**自动剪出高光合集**：

- 🤖 自动识别比赛里的每一分（回合）
- ✂️ 自动剪掉捡球、擦汗、发呆的死时间
- 🏆 挑出最精彩的回合（长回合、多板对攻）拼成一条集锦

全程在**你自己的电脑**上运行，视频不会上传。

## 使用说明

### Windows

1. 解压后双击 **`run.bat`**
2. 把要处理的视频文件**拖到窗口里**，按回车
3. 在弹出的画面里**按顺序点击球桌四角**（左上 → 右上 → 右下 → 左下），按 `c` 确认
4. 等分析跑完，高光合集生成在视频同目录下（文件名带 `_highlights`）

### macOS

1. 解压后第一次打开会有"无法验证开发者"提示：**右键点程序 → 打开 → 仍然打开**（只需一次）
2. 双击 **`run.command`**
3. 把视频拖进窗口 → 按回车 → 点球桌四角 → 按 `c` → 等分析完

> 提示：如果下载版提示"已损坏/无法打开"，右键点程序选"打开"一次即可。

### 视频要求

- 用**固定机位**拍的比赛或训练视频（手机放三脚架即可）
- 常见格式都支持（MP4、MOV）

## 常见问题

**Q：我不会编程，能用吗？**
A：能。下载解压就能用。

**Q：视频会上传到网上吗？**
A：不会。所有分析都在你本地电脑完成，视频不出你的机器。

**Q：收费吗？**
A：免费使用。如果它帮到了你，欢迎扫码打赏支持一下（见文末）。

**Q：剪出来的回合不对怎么办？**
A：通常是机位太低或画面太晃。尽量让摄像头固定、能看清整张球台。

**Q：源码会公开吗？**
A：目前源码不公开，只提供打包好的安装程序。
