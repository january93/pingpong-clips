# 小球大师 🏓

乒乓球比赛视频自动剪高光。打乒乓球录了视频，回放时却要一路拖进度条找精彩球？**小球大师**帮你**自动剪出高光合集**：

- 🤖 自动识别比赛里的每一分（回合）
- ✂️ 自动剪掉捡球、擦汗、发呆的死时间
- 🏆 挑出最精彩的回合（长回合、多板对攻）拼成一条集锦

全程在**你自己的电脑**上运行，视频不会上传，**免费使用**。

## 快速开始（macOS）

1. 下载 `pingpong-clips-macos.zip` 并解压
2. 第一次打开会有"无法验证开发者"提示：**右键点 `pingpong-clips` → 打开 → 仍然打开**（只需这一次）
3. 双击 **`run.command`**，进入**图形界面**
4. 把视频拖进窗口 → 按顺序点球桌四角 → 选片段 → 导出

> 提示：如果下载版提示"已损坏/无法打开"，右键点程序选"打开"一次即可。

## 图形界面使用说明

一次完整的剪辑流程共 7 步，全部在窗口里点点点完成：

1. **选择视频** — 拖入或点选，自动读出时长 / 分辨率 / 帧率
2. **标定球桌** — 在画面上按顺序点球桌四角（左上 → 右上 → 右下 → 左下），可用 `← →` 键换帧微调；标定会被记住，下次自动带出
3. **分析中** — 进度环 + 阶段文字，随时可取消
4. **选择片段** — 三个模式：
   - **全部回合**：导出识别到的所有回合
   - **精彩片段**：按「> 3 / > 5 / > 7 跳」档位筛选，表格里可逐条勾选
   - **自定义编辑**：进时间线编辑器，拖动每段起止手柄精修
5. **导出中** — 显示进度，可取消
6. **完成** — 视频预览 + 打开所在文件夹 + 再来一个

另外：

- **历史记录**：每次导出自动存档（含封面帧）。随时重新打开某次会话，**不用重跑分析**即可再次导出。
- **设置**：球识别模型（V2/V1）、置信度阈值、精彩档位、剪辑延边、设备（auto/cpu/cuda/mps）、ROI 开关等；「应用」后下次分析生效。
- **打赏**：导出完成后自动弹出右上角收款码卡片，也可以不理会。

### 视频要求

- 用**固定机位**拍的比赛或训练视频（手机放三脚架即可）
- 常见格式都支持（MP4、MOV）

### 命令行模式（可选）

图形界面已覆盖绝大多数使用场景；喜欢命令行的同学仍可这样用：

```bash
pingpong-clips --cli --input 视频.mp4 --calibrate --top-n 5
```

| 参数 | 作用 |
| ---- | ---- |
| `--top-n 数字` | 想剪几个精彩回合（默认 8 个） |
| `--min-bounces 数字` | 弹跳数低于这个值的回合不要（默认 3） |
| `--out 文件名` | 指定输出文件名 |

想调更多算法参数，改同目录下的 `config.toml`。

## 常见问题

**Q：我不会编程，能用吗？**
A：能。下载解压就能用，全程鼠标点一点。

**Q：视频会上传到网上吗？**
A：不会。所有分析都在你本地电脑完成，视频不出你的机器。

**Q：收费吗？**
A：免费。如果它帮到了你，欢迎扫码打赏支持一下（见文末）。

**Q：我用 Mac，能用吗？**
A：可以。见上方快速开始（macOS 用户）。

**Q：源码会公开吗？**
A：目前源码不公开，只提供打包好的安装程序。

**Q：剪出来的回合不对怎么办？**
A：通常是机位太低或画面太晃。尽量让摄像头固定、能看清整张球台，也可以在设置页或 `config.toml` 里调阈值。

**Q：历史记录存在哪？**
A：存本地应用数据目录（macOS：`~/Library/Application Support/xiaoju/pingpong-clips/`），不会上传。
